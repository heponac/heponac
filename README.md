# heponac

Installation d'[OpenJarvis](https://github.com/open-jarvis/OpenJarvis) (assistant IA modulaire).

```bash
./install.sh                 # crée .venv et installe openjarvis==1.0.4
source .venv/bin/activate
jarvis quickstart            # configuration guidée (modèle, clés, etc.)
jarvis doctor                # diagnostic
jarvis chat                  # discuter avec Jarvis
```

Python 3.10 à 3.13 requis.
